 AI-Based Acoustic Fault Diagnosis & Predictive Maintenance of Rotating Machinery
o Developed an AI-based acoustic analytics pipeline for detecting and classifying abnormal operating conditions
in rotating machinery using time-frequency signal representations.
o Applied signal preprocessing, FFT/STFT-based feature extraction and spectrogram generation to transform
raw acoustic signals into machine-learning-ready representations.
o Developed and compared CNN, CNN-LSTM and CNN-BiLSTM architectures to capture spectral and
temporal patterns associated with compressor and pump faults.
o Evaluated model performance using precision, recall, F1-score, confusion matrices and validation analysis
to identify the most reliable architecture.
o Implemented anomaly scoring to distinguish normal operating behaviour from potentially abnormal acoustic
signatures and support early fault detection.

o Developed an interactive visualization layer for monitoring predicted fault probabilities, anomaly trends and
equipment condition over time.
